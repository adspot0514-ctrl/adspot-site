상담문의

아직 접수된 상담문의가 없습니다.

    홈페이지 수정

    저장하면 홈페이지에 바로 반영됩니다. (새로고침 후 확인)

    지역 페이지

    페이지 보기

    저장하면 방문자와 검색엔진 모두 바뀐 내용을 보게 됩니다. 비워 둔 칸은 기본 문구가 쓰입니다.

    통계

    광고 vs 자연 유입

    광고 = 네이버 파워링크(자동 추적 URL·지역 광고 주소·?ch=pl), 자연 유입 = 검색·블로그·카페·다른 사이트, 직접·기타 = 주소 직접 입력·즐겨찾기. 상담 신청은 그 방문자가 처음 들어온 채널 기준입니다.

    일별 방문

    첫 페이지 (방문자가 처음 들어온 페이지)

    이탈 = 그 페이지 하나만 보고 아무 행동 없이 떠난 방문. 연락 = 전화·카톡 버튼 클릭.

    방문자 행동

    최근 방문 흐름 (최근 25명)

    페이지별

    유입 경로 (상세)

    광고 지역

    검색 키워드 (광고)

    기기

    방문 수는 페이지를 연 횟수, 방문자는 서로 다른 브라우저 수입니다. 검색 로봇과 관리자 페이지는 제외됩니다.
